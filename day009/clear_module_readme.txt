In order to get clear.py working, you must include pyautogui package in your project's workstation and configure a
hotkey set in your Python interpreter.
If you are in PyCharm, go to File -> Settings -> Keymap.
Click on "Others" folder and go down until you reach "Clear All" option and assign it a new hotkey set to work with.
Once you've done, go to clear.py
Write the same exact sequence as you introduced in Keymap settings in pyautogui.hotkey function
Finally, save your changes, and you can import "clear" function wherever you want in your project
